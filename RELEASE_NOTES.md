# SpectraCave 0.3.0-beta.1

First public, source-available beta. Free for noncommercial use; donations optional.

- Local FITS capture discovery and guided source selection.
- Named extractions, background subtraction, saturation rejection and repeatability checks.
- Dynamic star selection and a visually distinct comparison reference.
- Explicit pixel/wavelength views; no silent omission of uncalibrated selections.
- Optional calibration workspace and relative-response curve application to copies.
- Rainbow display, laboratory guides and cautious candidate-feature inspection.
- Optional AI evidence review and CSV/JSON exports.
- First-launch environment setup and launchers for macOS, Windows and Linux.

Important limits: requires Python 3.10+, first-launch internet and a writable app
folder. Not a signed native installer. Developed and browser-tested on macOS;
see CI for automated platform checks. No automatic chemical confirmation,
AAVSO integration/export, dark/flat correction, template matching or equipment
profiles. Not a hosted or multi-user service.
